## Deferred GPT-Pro Constraints

These apply only after a separate user-approved design and implementation plan.

4. Advisory only: consultation grants no route, verdict, or effect authority; parent context alone sends or imports a bounded question.
5. One send-state file: Codex and Claude share one small Pipeline-local file with one guarded send per key; parallel ledgers previously broke deduplication and no-retry accounting.
6. Reservation boundary: validation is correctable before reservation; after reservation, prompt, provider, transport, and attempt are immutable, and unavailable transport records failure and stops; fallback chains previously escaped spend and duplicate-send limits.
7. Content-free failure: error codes never echo rejected text, and raw prompts/responses stay out of Git, mail, logs, and durable transcripts; echoed rejection text previously became the leak.
8. Token boundaries: named secret formats may use whitespace-stripped views, but generic long-token detection may not; compact generic scans previously rejected benign prose.
9. Triggered consultation: consult only for an unsettled material tradeoff, authority/security-boundary change, genuinely distinct adversarial challenge, or explicit user request; default consultation previously created cost and delay without new authority.

## Shape Constraints

10. One canonical rule: other surfaces link here instead of copying lifecycle prose; mirrored rules previously required hand edits across many files.
11. Size tripwire: the combined future cross-model/GPT-Pro production delta stays below roughly 500 lines and never gets its own recovery plan; the deleted system grew to about 10,000 lines and four recovery campaigns.
12. Failure-backed controls: every control names the concrete failure it prevents; a control without a failure story is ceremony.

## Smallest Execution Shape

- No trigger: one writer and focused verification; no protocol artifact.
- Verification trigger: one writer, one non-author-model Operator, one GO/NITS/FAIL report.
- Coordination trigger: add coordinator state only for multiple writers, transferred unfinished ownership, overlapping mutable scope, or a real join.
- Effect trigger: reserve only the exact external action.
- Ask one review question once; repeat only for a changed diff or a stated, genuinely different question.
