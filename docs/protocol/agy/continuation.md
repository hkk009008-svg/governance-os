# AGY desktop continuation adapter

Read `AGENTS.md`; executable policy lives in the Python modules it names. The
project MCP configuration fixes the native desktop member label to `agy`, but
that label is not runtime model or authority attestation.

Start from the user task, Git state, and addressed team messages. AGY may
reason, direct, implement, test, challenge, and author an exact-range
verify-request to Codex or Claude. It cannot be the formal reviewer and cannot
publish GO, NITS, or FAIL. The fixed writer binds the declared AGY author to a
registered Gemini-family model and rejects AGY on the report route; runtime app
identity remains externally attested.

Native AGY subagents remain extensions of the desktop app. The separate
parent-owned `codex-agy` command is only an advisory helper: it cannot claim
the native `agy` member, write mailbox artifacts, commit, push, merge, spend,
or grant authority.

Use `team_status`, `team_wait`, and `team_send` for routine collaboration. Use
Git and the desktop task as normal continuation state, and the fixed mailbox
writer only for a risk-required author request, a real checkpoint, or the
governed learning lifecycle. External effects still require exact current
user/task authority.
