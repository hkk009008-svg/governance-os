# Incident Log

Emergency protocol requires a durable note here within one session after any
emergency resolution.

Use this file only for events that match the emergency categories in the
protocol: production-affecting or user-data-integrity issue, security-critical,
active bleed-rate, or external time-pressure.

## Template

```markdown
## YYYY-MM-DD - short incident title

- Category:
- First noticer / acting seat:
- Impact:
- Mitigation:
- Verification:
- Follow-up protocol gap:
```
