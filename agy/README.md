# Dr. ROOTEM 초프리미엄 바이오 헬스케어 메타버스 웹앱

본 프로젝트는 주식회사 루템바이오의 **닥터루템 (Dr. ROOTEM)** 브랜드를 기반으로, 최첨단 Web 기술(HTML5 Canvas 2D Particle Engine, 3D Tilt Dynamic Glassmorphism, Bio-Radar Health Radar Chart)을 집약하여 구축한 **가장 시각적으로 뛰어난 인터랙티브 웹 애플리케이션**입니다.

---

## 주요 차세대 시각적 & 인터랙티브 기능

1. **HTML5 Canvas 2D 파티클 스페이스 엔진 (`#particleCanvas`)**:
   - 화면 전체에 실시간으로 펼쳐지는 나노 분자 파티클 콘스텔레이션 캔버스 백그라운드.
   - 마우스 커서 위치를 부드럽게 추적하는 앰비언트 라이트 앰비언트 엠버글로우 (`#cursorGlow`).

2. **3D dynamic 카드 호버 틸트 시스템**:
   - 마우스 이동 위치에 따라 원근감(Perspective 1000px) 3D 회전 및 글래스모피즘 빛 반사 효과 적용.

3. **인터랙티브 나노 바이오 성분 매트릭스 (`#matrix`)**:
   - 포스파티딜세린, 리포좀 비타민C, 독일산 맥주효모, 루테인 지아잔틴, 바나바잎 코로솔산의 분자 구조, 순도, 흡수율, 임상 데이터 인터랙티브 진단.

4. **실시간 바이오 레이더 헬스 다이어그램 (`#dashboard`)**:
   - 모니터 노출시간, 수면시간, 두뇌사용량, 야외활동 슬라이더에 따라 Canvas 2D 레이더 차트 및 바이오 스코어가 실시간 동적 렌더링.

5. **스마트 장바구니 & 무료배송 프로그레스 드로어 (`#cartDrawer`)**:
   - 실시간 총 결제금액 계산, 무료배송 달성 프로그레스 바, 30,000원 웰컴 쿠폰 자동 감면.
