# Dr. ROOTEM 초프리미엄 바이오 헬스케어 메타버스 웹앱 (실물 제품 화보 적용 버전)

본 프로젝트는 주식회사 루템바이오의 **닥터루템 (Dr. ROOTEM)** 공식 브랜드스토어에 고화질 실물 제품 스튜디오 화보(Assets: PS 70, 리포좀 비타민C, THE 맥주효모 4000, 쏘팔메토 루테인, 바나바 혈당케어, 초임계 rTG 오메가3)를 전면 적용한 인터랙티브 웹 애플리케이션입니다.

---

## 주요 차세대 시각적 & 실물 화보 통합 기능

1. **실물 스튜디오 제품 화보 시스템 (`assets/*.jpg`)**:
   - **두뇌엔 PS 70**: 에메랄드 골드 에디션 병 화보
   - **리포좀 비타민C 1000**: 앰버 오렌지 비타민 병 화보
   - **THE 맥주효모 4000**: 코스믹 퍼플 비오틴 병 화보
   - **쏘팔메토 & 루테인**: 코발트 블루 전립선/눈 영양 병 화보
   - **바나바잎 혈당케어**: 루비 레드 코로솔산 병 화보
   - **초임계 rTG 오메가3**: 오션 아쿠아 오메가3 병 화보

2. **54+ 실구매 고객 리뷰 데이터베이스 & 검색/페이징 엔진**:
   - 키워드 검색 바 (`#reviewSearchInput`), 페이징 버튼 (`#loadMoreReviewsBtn`), 공감 투표, 실시간 리뷰 작성 모달.

3. **HTML5 Canvas 2D 파티클 스페이스 엔진 & 3D 틸트 호버**:
   - 파티클 콘스텔레이션 캔버스 백그라운드, 커서 앰비언트 엠버글로우, 원근감(Perspective 1000px) 3D 카드 틸트.
