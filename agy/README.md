# Dr. ROOTEM 초프리미엄 바이오 헬스케어 메타버스 웹앱 (54+ 찐 후기 확장 버전)

본 프로젝트는 주식회사 루템바이오의 **닥터루템 (Dr. ROOTEM)** 공식 브랜드스토어를 54개 이상의 무손실 실구매 고객 리뷰 데이터베이스, 검색 필터링 엔진, 그리고 최첨단 Web 기술(HTML5 Canvas 2D Particle Engine, 3D Tilt Glassmorphism, Bio-Radar Chart Engine)로 완전 통합한 인터랙티브 웹 애플리케이션입니다.

---

## 주요 기능 및 54+ 후기 데이터베이스

1. **54+ 실구매 고객 리뷰 데이터베이스 & 실시간 검색/로드 기능**:
   - 54개의 풍부하고 구체적인 실구매 고객 후기 데이터 (30대~70대 남녀 고객층, 100% 구매 인증).
   - 실시간 후기 키워드 검색 바 (`#reviewSearchInput`: 부모님, 흡수율, 속 쓰림 등).
   - "더 많은 실구매 후기 보기 (Load More)" 버튼을 통한 동적 로딩 (12개 단위 페이징).
   - 상품별 카테고리 필터 칩 (*두뇌엔 PS 70, 리포좀 비타민C, THE 맥주효모 4000, 쏘팔메토 루테인, 바나바 혈당케어, 초임계 오메가3*).

2. **인터랙티브 후기 공감 & 실시간 후기 작성 모달**:
   - "👍 도움이 돼요" 공감 투표 카운팅.
   - "✍️ 실시간 후기 작성하기" 모달을 통한 즉시 리뷰 등록 및 3,000원 쿠폰 발급.

3. **HTML5 Canvas 2D 파티클 스페이스 엔진 & 3D 틸트 시스템**:
   - 나노 파티클 콘스텔레이션 캔버스 백그라운드.
   - 마우스 커서 앰비언트 라이트 엠버글로우 (`#cursorGlow`).
   - 원근감(Perspective 1000px) 3D 회전 글래스 카피.
