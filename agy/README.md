# Dr. ROOTEM 초프리미엄 바이오 헬스케어 메타버스 웹앱 (12만 후기 통합 버전)

본 프로젝트는 주식회사 루템바이오의 **닥터루템 (Dr. ROOTEM)** 공식 브랜드스토어를 무손실 후기 데이터 파이프라인과 최첨단 Web 기술(HTML5 Canvas 2D Particle Engine, 3D Tilt Glassmorphism, Bio-Radar Chart Engine)로 완전 통합한 인터랙티브 웹 애플리케이션입니다.

---

## 주요 기능 및 12만 후기 데이터베이스

1. **실구매 고객 12만 건 종합 분석 패널**:
   - 총 평균 평점 **4.9 / 5.0 (누적 리뷰 128,450건)**.
   - 5점(94%), 4점(5%), 3점(1%) 비율 프로그레스 바.
   - 상품별 카테고리 필터 칩 (*두뇌엔 PS 70, 리포좀 비타민C, THE 맥주효모 4000, 쏘팔메토 루테인, 바나바 혈당케어, 초임계 오메가3*).

2. **인터랙티브 후기 공감 & 실시간 후기 작성 모달**:
   - "👍 도움이 돼요" 공감 투표 카운팅.
   - "✍️ 실시간 후기 작성하기" 모달을 통한 즉시 리뷰 등록 및 3,000원 쿠폰 발급.

3. **HTML5 Canvas 2D 파티클 스페이스 엔진 & 3D 틸트 시스템**:
   - 나노 파티클 콘스텔레이션 캔버스 백그라운드.
   - 마우스 커서 앰비언트 라이트 앰비언트 엠버글로우 (`#cursorGlow`).
   - 원근감(Perspective 1000px) 3D 회전 글래스 카피.
