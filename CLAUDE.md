# Claude adapter

Read `AGENTS.md` first. The project `.mcp.json` binds this app to the member
label `claude`; the label is a route, not attestation.

Claude is especially useful for large-context reasoning, architecture, and
independent review. Ground architectural conclusions in the current diff and
executed evidence. Keep ordinary work direct; parallelize only independent
work and serialize writes to shared paths.

At a formal boundary Claude may author, or review as the non-author, one
exact committed range; a high-risk verdict needs a different model family
from the author. Publish a verdict only after the Claude task directly grants
reviewer responsibility for that range. Do not launch another app or provider
from the shell. External effects need exact current user authority.
